# 연세세브란스치과 MVP 홈페이지 목업

- 리봄치과 레퍼런스의 구조를 참고한 신규 개원용 1차 오픈 목업입니다.
- 실제 사이트 복제가 아니라, 병원 정보에 맞춘 별도 디자인/문구/구조입니다.
- 상담 폼은 화면만 구현되어 있으며 실제 이메일 전송 기능은 연결되어 있지 않습니다.
- 네이버 지도, 카카오톡 채널, 전화번호, 비급여 수가표, 개인정보처리방침은 실제 정보로 교체해야 합니다.
